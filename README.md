# Daily Budget Manager

Веб-калькулятор дневного бюджета: показывает, сколько можно тратить в день, чтобы уложиться до конца периода, и ведёт историю трат и пополнений.

Репозиторий: https://github.com/glneed/higher-web-practice-calculator

Гущин Леонид Олегович, М4228

## Стек

- TypeScript + Vite
- Tailwind CSS
- Zod (валидация данных)
- idb (обёртка над IndexedDB)

## Запуск проекта

### Требования

- Node.js 18+

### Установка и запуск

```bash
npm install   # установить зависимости
npm run dev   # запустить dev-сервер (по умолчанию http://localhost:3000)
```

Данные (бюджет и транзакции) хранятся в IndexedDB браузера, поэтому при первом запуске откроется стартовая страница.

### Другие команды

| Команда                | Назначение                            |
| ---------------------- | ------------------------------------- |
| `npm run build`        | Production-сборка в `dist/`           |
| `npm run preview`      | Просмотр собранной сборки             |
| `npm run type-check`   | Проверка типов TypeScript             |
| `npm run format`       | Форматирование кода Prettier          |
